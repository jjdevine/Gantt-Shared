Person import/export

Export produces: {"tasks":[ ... ]}. Import accepts either this object or a bare array of tasks. All imported tasks are assigned to the specified person and replace any existing tasks for that person. A name that is not in the plan yet creates a new person; you will be asked to confirm.

Shared repository settings

Stored only in this browser. Needs read and write access to the repository's contents. Collaborators on a personally owned repository use a classic token with the repo scope.

Conflicting changes

Keep theirs discards your changes to this person and reloads the repository version. Keep mine overwrites the repository version with yours. Decide later leaves both as they are; your changes stay in this browser and nothing is written for this person until you choose.
